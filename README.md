\# Python 2048 Game (with GUI)



This project is a desktop implementation of the classic 2048 game, developed using Python and the Tkinter library.



\## 🚀 Features



\* All the basic 2048 game logic (`logic.py`)

\* A simple and colorful graphical interface built with Tkinter (`gui\_2048.py`)

\* Cell colors that change based on the number

\* Win ("You've reached 2048!") and lose ("Game Over!") states



\## 📋 Requirements



\* Python 3.x

\* Tkinter (Usually comes standard with Python)



\## 🎮 How to Run



1\. Clone or download this repository to your computer.

2\. Open a terminal (command prompt) and navigate to the project folder.

3\. Run the following command:



```bash

python gui\_2048.py
